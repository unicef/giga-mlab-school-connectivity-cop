# Materials

Resources shared within the Connectivity Community of Practice, organized into dated subfolders — one per topic or event. Each subfolder has its own README with details.

## Index

- [`qoe-measurements-design.md`](./qoe-measurements-design.md) — Design doc for next-generation "learning-ready" connectivity measurements (Workstream 1, Task 1.1 of the [research agenda](../research_agenda.md)).
- [`ping-measurements-methodology.md`](./ping-measurements-methodology.md) — Design doc on designing ping/latency measurement for schools and on evolving Giga's measurement capability beyond speed tests (Workstream 1, Task 1.1 of the [research agenda](../research_agenda.md)).
- [`ping-responsiveness-baseline.md`](./ping-responsiveness-baseline.md) — Measured baseline for the inward-probing design in the methodology note: how often school egress addresses actually answer a probe, across 25 countries (August 2026).
- [`20260311_Connectivity_CoP_Launch_Event_Slides.pdf`](./20260311_Connectivity_CoP_Launch_Event_Slides.pdf) — Slides from the CoP launch event, 2026-03-11.
- [`2026-05-EduPlatformsDatabase/`](./2026-05-EduPlatformsDatabase) — Structured database of national digital learning platforms across 184 countries.
- [`2026-05-IQB-Edu/`](./2026-05-IQB-Edu) — IQB-Edu (Internet Quality Barometer for Education) framework and the Moldova schools pilot: presentation and Jupyter notebooks.
